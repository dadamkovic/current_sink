The design is intended to be a programmable current sink controllable manually using an encoder or over USB interface.
It ECU includes:
- 2 parallel separately controlled MOSFETs
- starburst type LCD display with 8 segments + driver IC
- symmetrical power rails +/- 5V
- USB optical isolation protection
- 2 channel DAC
- current monitoring
- optional 'PID' feedback control loop realized using cascaded op-amps 

Current state - HW is finished and a prototype was produced. SW library for control of the display is ready and included in the SW files.
